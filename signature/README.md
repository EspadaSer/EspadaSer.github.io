# Firma de Gmail

Archivos de la firma para copiar y pegar en Gmail:

- [Firma recomendada](https://espadaser.github.io/signature/) — sin foto, estilos inline.
- [Firma con foto](firma-con-foto.html) — incluye el avatar incrustado; Gmail puede eliminarlo.
- [Versión texto plano](firma.txt) — respaldo si Gmail no conserva estilos.
- [Instrucciones](INSTRUCCIONES.txt)

## Cómo ponerla en Gmail

1. Abre la [firma recomendada](https://espadaser.github.io/signature/).
2. `Ctrl+A` y `Ctrl+C`.
3. Gmail → **Settings** → **General** → **Signature**.
4. Pega dentro del editor y guarda los cambios.

Las tres píldoras pequeñas (GitHub, LinkedIn y Projects) se cargan desde este mismo sitio, así que no dependen de archivos locales.
