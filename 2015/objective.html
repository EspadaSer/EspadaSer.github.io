Objective

The main goal of this project is to design, assemble, test and optimize a PV analyzer and I-V curve tracer device to check the performance of photovoltaic solar systems. The device must be able to measure the I-V curve of a PV module with sufficient accuracy (aiming for a total added measurement error of 1%).

The device also has to meet other requirements: it must be as autonomous as possible, portable with enough battery life to take measurements, able to convert the measured values to STC (standard test conditions) using the UNE-EN 60891 standard, and as cheap as possible.

For this purpose I decided to use Arduino microcontrollers to build a device that achieved all the required characteristics. Arduino is an open source platform spread all around the world that provides a lot of flexibility while keeping things simple, backed by a large community and enough processing power. It is especially relevant in the goal to keep the costs of the project as low as possible, as the devices used are typically mass-produced to decrease the costs.

After choosing Arduino and running some feasibility tests, I split the system into two devices. The first device is a PV reference sensor that measures the irradiance and temperature of the cells and send the data to the main device using radio signals. The second device is the PV analyzer and I-V curve tracer that makes use of a capacitive load to measure the voltage and current of the desired PV module and turn the data into STC conditions using the information received from the other device.

This configuration allows me to set up the PV reference sensor in a static place to measure the irradiance and temperature, while the user performs the measurements with only the PV analyzer. This increases the speed of the measurements and thus the efficiency of the process, as I don't have to relocate the calibrated solar cells of the reference every time we want to measure. It also allows us to decrease the weight of the PV analyzer, improving its portability.

The communication of the system is done using wireless technology under the ZigBee protocol. This technology uses radio signals to send unidirectional information from the reference sensor to the PV analyzer. The analyzer receives the data passively and when a measurement is done it stores and uses the received data in order to make the extrapolation of the I-V curve.

The final result is the I-V and P-V curve of the PV module under STC conditions, where we can easily find the values of short-circuit current (Isc), open-circuit voltage (Voc) and the maximum power point (Mpp).

All the data collected can be used to check if the performance of the PV module is correct as well as to check if there are problems in the modules themselves, like mismatch or an accelerated degradation of the panels.
